These are the content-authoring notes that used to live inside `public/`
(e.g. `public/images/journey/betra/README.md`). They were moved here before
the production deploy because anything under `public/` is served as a static
file — a folder of internal "drop your image here" notes has no reason to be
publicly downloadable at `yoursite.com/images/journey/betra/README.md`.

Nothing in the app reads from this folder; it's just reference material for
whoever is adding new journey/profile assets. The paths below mirror where
each note originally sat under `public/`.
